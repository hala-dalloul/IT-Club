# مسارك التقني

Create a professional, modern, interactive web game for new students at University College of Applied Sciences (UCAS), developed by UCAS IT CLUB.

The main purpose of the game is to help a new student who is confused about which IT specialization to choose discover the most suitable academic path through a fun, smooth, game-like experience.

This must NOT look like a traditional questionnaire, form, survey, or boring career test.

It should feel like a modern interactive adventure / digital journey where the student explores different paths and discovers their strengths.

PROJECT NAME:

"اكتشف مسارك"

Subtitle:

"رحلتك التقنية تبدأ من هنا"

Brand:

UCAS IT CLUB

"تخيل عندك فكرة جديدة، شو الجزء اللي بتحب تكون مسؤول عنه؟"

Use visual cards instead of plain radio buttons.

==================================================

SCORING SYSTEM

==================================================

Implement a real internal scoring system.

There are exactly 5 specialization paths:

1. تكنولوجيا الوسائط المتعددة

2. تصميم وتطوير مواقع الويب

3. تصميم وبرمجة الألعاب

4. البرمجيات وقواعد البيانات

5. تصميم وبرمجة تطبيقات الموبايل

Each answer should contribute different points to one or more specializations.

Do NOT show the score to the student while playing.

The algorithm should calculate the strongest match at the end.

If two paths are very close, show:

"عندك أكثر من مسار مناسب لك!"

Then show the top 2 recommended paths instead of forcing only one.
