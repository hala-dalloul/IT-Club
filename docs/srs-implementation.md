# حالة متطلبات النادي

المرجع الحالي: [وثيقة SRS الإصدار 2.0](SRS_UCAS_IT_Club_Website_v2.docx)، مراجعة 14 سبتمبر 2026. يحل هذا الملخص محل الوصف القديم الذي كان يتضمن المشاريع والإنجازات ونموذج التواصل وتخزين الطلبات في Supabase.

| الجزء | النطاق الحالي | متطلبات التشغيل |
| --- | --- | --- |
| الصفحات | الرئيسية، من نحن، الفريق، الشركاء، الفعاليات، الانضمام، التواصل الاجتماعي | محتوى معتمد وترجمات وروابط صحيحة |
| المشاريع والإنجازات | أزيل العرض والإدارة والمسارات العامة | لا يعني ذلك حذف السجلات التاريخية |
| الفريق | الهيئة الإدارية من قائمة اللجان، ثم الإعلام والعلاقات العامة والأنشطة | isFounder محفوظ للتوافق ولا يمنح صلاحيات دخول |
| الانضمام | بريد smail.ucas.edu.ps، رقم جامعي 9 أرقام، هاتف اختياري يبدأ 056 أو059 بطول 9 أو10 | نشر نسخة Code.gs الحالية |
| الطلبات | Google Sheets فقط للطلبات الجديدة، مع سقف وعدّاد ومنع تكرار | FORM_KIND=join وصلاحيات الورقة ونشر عام مناسب |
| الاستلام والقبول | تأكيد الاستلام بعد الحفظ دون رقم تأكيد | القبول وإرسال رسالته إجراء إداري خارج التنفيذ الحالي |
| التواصل | بطاقات LinkedIn وInstagram وFacebook | تفعيل الرسائل لدى المنصات؛ لا نموذج رسائل جديد |
| الإدارة | Supabase Auth، محتوى وصور، إعدادات ومحررون للمدير العام | إنشاء حسابات وربط الأدوار وسياسات RLS |
| الصور | مكتبة وسائط وضغط ومراجع استخدام ومنع حذف المستخدم منها | إعداد Storage والسياسات؛ الصور العامة قابلة للنسخ |
| الزيارات | عدد جلسات بمعرف عشوائي، وليس أشخاصًا فريدين | تطبيق هجرة visits؛ يظهر شرطة عند تعذر الخدمة |
| الهوية | الشعار الحالي والألوان، تحميل بالشعار وحركة الدائرتين | مراعاة تقليل الحركة وقابلية القراءة |
| الفوتر | التواصل وروابط اجتماعية | لا رابط إدارة أو انضمام |
| الاستضافة | Cloudflare وبناء ثابت، الكود على GitHub | نشر الفرع الصحيح ومعالجة المسارات |
| اللعبة | مسار مستقل /pathfinder | خارج التنقل الرئيسي للنادي |
| التشات بوت | دراسة مستقبلية فقط | اعتماد منفصل قبل التنفيذ |

الطلبات والرسائل التاريخية في Supabase لا يثبت حذفها بمجرد وجود ملف delete-legacy-submissions.sql. يجب التحقق من تنفيذ التنظيف ومراجعة السياسات القديمة غير المستخدمة بشكل مستقل. لا تؤكد اختبارات البناء المحلية اكتمال إعداد الخدمات الحية أو تحقق أهداف الأداء والتوفر.
