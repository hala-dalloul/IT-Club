# متابعة تنفيذ متطلبات موقع النادي

هذه المتابعة تفصل العمل المنفذ في الكود عن التفعيل الحقيقي في حساب النادي. المرجع هو SRS إصدار 1.0 بتاريخ 23 أغسطس 2026 المرفق من المستخدم. لا يُعد أي نص إجرائي في الوثيقة موافقة مستقلة على نشر بيانات أو شراء خدمات.

| المجموعة      | التنفيذ                                                                                                       | ما يلزم قبل الاعتماد النهائي                                                            |
| ------------- | ------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| FR-1 الرئيسية | شعار، تنقل، دعوة للانضمام، إحصائيات من السجلات، أحدث ثلاثة مشاريع وآخر فعالية                                 | بيانات النادي الفعلية                                                                   |
| FR-2 من نحن   | نصوص قابلة للإدارة ومجالات النادي الأربعة                                                                     | إدخال الرؤية والرسالة والأهداف المعتمدة                                                 |
| FR-3 المشاريع | شبكة، نوع، سنة، بحث، تفاصيل، صور وتقنيات وروابط، ربط الأعضاء                                                  | إدخال مشاريع فعلية                                                                      |
| FR-4 الفريق   | قسم المؤسسين، اللجان، صفحات أعضاء وروابط ومشاريع مرتبطة                                                       | بيانات وصور أعضاء معتمدة                                                                |
| FR-5 وFR-6    | خط زمني للإنجازات وشعارات الشركاء وروابطهم ونوع الشراكة                                                       | المحتوى المعتمد                                                                         |
| FR-7          | قائمة أخبار وفعاليات، فلتر قادمة/سابقة، تفاصيل وصور وتاريخ                                                    | المحتوى المعتمد                                                                         |
| FR-8          | نماذج مع تحقق وكتابة إلى Firestore، عرض الرسائل والطلبات للإدارة                                              | إعداد Firebase؛ البريد الإلكتروني مؤجل لحين تحديد الجهة والموافقة                       |
| FR-9          | دخول Firebase، Dashboard، CRUD، طلبات، رسائل، رفع ومعاينة صور، ضبط المحررين، إعدادات المدير، بيانات آخر تعديل | إنشاء حساب المدير الأول وتفعيل خدمات النادي؛ إنشاء حسابات Authentication يتم من Console |

| NFR الأداء    | فصل مسار اللعبة والموقع، تحميل الصور كسولًا، ضغط صور المحتوى                                                  | قياس 4G الحقيقي ومراجعة أجهزة ومتصفحات فعلية                                            |
| NFR الصيانة   | وحدات محتوى وبيانات منفصلة، README وتعليمات تهيئة وبناء واختبارات                                             | تسليم الحسابات وتدريب لجنة الإعلام                                                      |
| NFR النشر     | بناء Lovable محفوظ وبناء ثابت مستقل لـFirebase Hosting                                                        | إعداد المشروع والنطاق؛ لم يُنفذ نشر سحابي                                               |

## ثوابت الحماية من التغيير

لم تتغير قيم أوزان اللعبة ولا الأسئلة ولا الألوان في `styles.css`. استُبدلت صورة الشعار المرفقة كما هي مع `object-fit: contain`، وأضيف رابط للموقع في تذييل اللعبة. بقي مسار اللعبة `/`، وأضيف موقع النادي تحت `/club` تجنبًا لتغيير التجربة الأصلية.

## التحقق

اختبارات Firestore تغطي الزائر والمستخدم المسجل غير الإداري والمحرر والمدير العام، وخصوصية الطلبات والرسائل، وتزوير الحالة وحقول التدقيق، وإلغاء صلاحية المحرر. اختبارات Storage تغطي صلاحيات الرفع ونوع الملف وحجمه وملكية مسار الرفع ومنع الاستبدال.

النجاح المحلي لا يثبت وصول رسائل بريد أو تشغيل قاعدة بيانات إنتاج أو زمن تحميل معين على شبكة 4G. مراجعة التفاعل في المتصفحات ودقة العرض على الأجهزة وتدريب اللجنة تبقى من معايير القبول التي تحتاج تنفيذًا على النسخة المفعلة.
