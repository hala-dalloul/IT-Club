# فصل الأخبار والفعاليات

تشغيل `supabase/migrations/202609190001_news_content.sql` مرة واحدة في Supabase SQL Editor قبل حفظ أخبار جديدة.

- يبقى التخزين في `club_content`، مع نوع مستقل `kind = news` للأخبار و`kind = events` للفعاليات.
- لا يعاد تصنيف المحتوى القديم تلقائيًا، ولا تحذف أي سجلات.
- تتيح قائمة «نوع المحتوى» في نموذج الإضافة والتعديل حفظ خبر أو فعالية ونقل المحتوى بين النوعين.
- يبقى المعرّف والصور وتاريخ الإضافة عند تغيير النوع. تعمل روابط التفاصيل القديمة من كلا المسارين.
- لكل نوع قسم في الإدارة وصفحة عامة. الرئيسية تعرض الأخبار، وعداد الفعاليات لا يحتسب الأخبار.
- يحتاج كلا النوعين تاريخًا. تحتاج الفعالية حالة قادمة/سابقة، ولا يرسل الخبر هذه الحالة.
- يضم هذا التحديث قواعد التحقق السابقة للجان وتصنيف الأعضاء وترتيب الهيئة الإدارية.
